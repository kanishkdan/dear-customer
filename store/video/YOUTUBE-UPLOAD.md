## Store update

Open the existing Dear Customer item in the Chrome Web Store developer dashboard. Under Store listing → Graphic assets, replace the promotional video URL, including any localized entry that still references the removed upload. Save draft and submit the listing update for review. A video-only metadata change does not require a new extension ZIP or a version bump. The currently published extension remains available while the update is reviewed.

Source: https://developer.chrome.com/docs/webstore/update
